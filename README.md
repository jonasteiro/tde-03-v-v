# Calculadora de Desconto: TDD x Abordagem Tradicional

Projeto acadêmico que implementa uma calculadora de desconto em Java de duas formas diferentes, para comparar o desenvolvimento orientado a testes (TDD) com a abordagem tradicional.

## Arquivos

| Arquivo | Descrição |
|---|---|
| `CalculadoraDescontoTDD.java` | Implementação da calculadora desenvolvida seguindo TDD (testes escritos antes do código). |
| `CalculadoraDescontoTDDTeste.java` | Testes unitários usados para guiar o desenvolvimento da versão TDD. |
| `CalculadoraDescontoTradicional.java` | Implementação da calculadora desenvolvida de forma tradicional (código primeiro, testes depois). |
| `CalculadoraDescontoTradicionalTest.java` | Testes unitários escritos após a implementação tradicional. |

## Objetivo

Comparar as duas abordagens de desenvolvimento, observando:

- a ordem em que código e testes são escritos;
- a cobertura e a qualidade dos testes;
- a clareza e a simplicidade do código final.

## Tecnologias

- Java
- JUnit (testes unitários)
- IntelliJ IDEA

## Como executar

1. Clone o repositório:
   ```bash
   git clone <url-do-repositorio>
   ```
2. Abra os arquivos em uma IDE Java (por exemplo, IntelliJ IDEA).
3. Adicione o JUnit ao projeto, caso ainda não esteja configurado.
4. Execute as classes de teste (`CalculadoraDescontoTDDTeste` e `CalculadoraDescontoTradicionalTest`).
